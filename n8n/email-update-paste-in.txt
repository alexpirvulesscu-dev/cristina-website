HOW TO UPDATE THE EMAIL IN n8n (two steps, about 5 minutes)

Open your workflow "Cristina - Contact form" in n8n.

=== STEP A: the code step called "Check and tidy" ===
1. Double-click "Check and tidy".
2. Click in the code box, select everything (Cmd + A) and delete it.
3. Paste the whole block below, then close the panel.

----- START OF BLOCK A -----
// Tidies what the website form sent and decides if it is a real enquiry.
// The form sends JSON; n8n puts it under "body".
const raw = $input.first().json.body;
let b = {};
try { b = typeof raw === 'string' ? JSON.parse(raw) : (raw || {}); } catch (e) { b = {}; }

// trim, cap the length, and stop line breaks sneaking into single-line fields
const clean = (s, n) => String(s == null ? '' : s).replace(/\r/g, '').trim().slice(0, n);
const name = clean(b.name, 120).replace(/\n/g, ' ');
const email = clean(b.email, 200).replace(/\s/g, '');
const message = clean(b.message, 4000);

// real enquiry = they ticked the consent box, the hidden "website" trap is empty,
// every field is filled in, and the email looks like an email
const ok = b.consent === true && !b.website && !!name && !!message &&
           /^[^@\s]+@[^@\s]+\.[^@\s]+$/.test(email);

// ---- prepare the text for the designed email. Everything a patient typed is made safe first,
// so nothing they write can change how the email looks or behave like code.
const esc = (s) => String(s).replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;');
const firstName = name.split(' ')[0] || name;
let sentLocal = clean(b.sentAt, 40);
try {
  const d = new Date(sentLocal);
  if (!isNaN(d)) sentLocal = d.toLocaleString('en-GB', { timeZone: 'Europe/Bucharest', day: 'numeric', month: 'long', year: 'numeric', hour: '2-digit', minute: '2-digit' }) + ' (Bucharest time)';
} catch (e) {}
const replyHref = 'mailto:' + email + '?subject=' + encodeURIComponent('Your consultation request') +
  '&body=' + encodeURIComponent('Dear ' + firstName + ',\n\nThank you for getting in touch.\n\n');

return [{ json: {
  ok, name, email, message, page: clean(b.page, 300), sentAt: clean(b.sentAt, 40),
  nameHtml: esc(name), firstNameHtml: esc(firstName), emailHtml: esc(email),
  messageHtml: esc(message).replace(/\n/g, '<br>'),
  sentLocal: esc(sentLocal), replyHref: esc(replyHref)
} }];
----- END OF BLOCK A -----

=== STEP B: the step called "Send to Cristina's inbox" ===
1. Double-click "Send to Cristina's inbox".
2. Subject: click the field, select everything, and paste:

----- START OF SUBJECT -----
={{ 'New consultation request: ' + $json.name }}
----- END OF SUBJECT -----

3. Email Type: change "Text" to "HTML".
4. Message: click the field, select everything, delete it, and paste the block below.
   (If n8n shows the field as plain text, hover it and choose "Expression" first so it shows the {{ }} parts.)
